# Focus — Klaviyo × Upsell

Guide e-commerce autonome consacré à Klaviyo et à l’application Upsell sur Shopify, conçu pour GitHub Pages.

## Aperçu local

Ouvrir directement `index.html`, ou lancer un serveur statique dans ce dossier :

```powershell
python -m http.server 4173
```

Puis ouvrir `http://127.0.0.1:4173`.

## Déploiement GitHub Pages

1. Créer un dépôt GitHub.
2. Ajouter `index.html`, `styles.css`, `script.js` et `favicon.svg` à la racine.
3. Dans **Settings → Pages**, publier la branche principale depuis la racine.

Le site n’a ni build ni dépendance externe. La progression et la checklist sont sauvegardées localement dans le navigateur.
